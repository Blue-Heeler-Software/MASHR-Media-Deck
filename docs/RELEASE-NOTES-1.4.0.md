# MASHR Media Deck 1.4.0

The first Blue Heeler Software preview of MASHR Media Deck turns a Pixel-class Android phone into a local, glanceable PC media controller for gaming.

## Highlights

- One-screen portrait deck with large, obvious controls.
- Artwork, metadata, and a continuously updating timeline.
- YouTube creator chapter markers and tappable **SCENES** list without an extension.
- Correct NVIDIA replay state: arm the buffer when it is off, save with the configured shortcut when it is ready.
- Focus-preserving media-window monitor cycling.
- Hold-to-use Alt+Tab with previous/next window navigation.
- Signed phone pairing and recommended single-phone LAN restriction.

## Install

1. Build or download the attached developer-preview APK.
2. Install the Windows companion from the same source revision.
3. Configure paired-phone LAN access.
4. Enter the six-digit tray pairing code on the phone.

The attached APK uses the Android debug signing key and is intended for direct developer/device testing, not store distribution.

## Compatibility

- Android 8 or later; verified on Pixel 7.
- Windows 10/11 with .NET 10; verified on Windows 11.
- YouTube/YouTube Music in Brave, Chrome, or Edge; Spotify; VLC fallback; and compatible Windows global media sessions.

See [SECURITY.md](../SECURITY.md) before enabling LAN access.
